# 2.1 — Задача F_oP → H(z)

## В чём состоит мост

MULTING утверждает: скопления галактик создают дополнительную силу F_oP,
которая добавляется к стандартному расширению Хаббла. Чтобы получить из
этой силы наблюдаемую функцию H_MULT(z), нужен «мост» — явная вычислительная
процедура, переводящая силовой закон в космологическую историю.

Мост требует знания трёх вещей о «типичном скоплении» на каждую эпоху z:

| Переменная | Смысл | Единицы |
|---|---|---|
| `k_A(z)` | суммарная кинетическая энергия объектов внутри скопления / c² | M☉ |
| `r_A(z)` | характерный радиус скопления | Мпк |
| `D_{C:AB}(z)` | расстояние между соседними скоплениями | Мпк |

Из этих трёх функций и силы F_oP получается H_MULT(z) — и именно это
вычисление проект пытался воспроизвести независимо от опубликованной
таблицы результатов.

## Q1, Q2, Q3 — три вопроса, которые нельзя разделить

Формализация задачи свелась к трём вопросам, отправленным доктору
Бакхольцу:

- **Q1** — какая именно формула связывает F_oP и H(z)?
- **Q2** — каковы функции k_A(z), r_A(z), D_{C:AB}(z)?
- **Q3** — что физически представляют собой параметры β_d, β_q?

Эти вопросы неразделимы на практике: без Q1 нельзя проверить, правильно ли
подставлены Q2; без Q2 нельзя протестировать формулу из Q1 на реальных
данных. Ни один из них не имеет значения в изоляции от двух других.

## Почему это была плохо поставленная обратная задача

У проекта был результат вычисления — таблица H_MULT(z) для одиннадцати
значений z — но не было входных данных, которые к нему привели. Это
классическая обратная задача: попытка восстановить входные функции по
конечному результату. Такие задачи в общем случае некорректны по Адамару —
малые изменения в допущениях о входных данных дают большие расхождения на
выходе, и без дополнительного регуляризатора решение не единственно.

Здесь регуляризатором мог быть только один источник: сам автор теории.
Три письма (12 и 17 июня, разговор 14 июня — глава 2.4) были попыткой
получить этот регуляризатор напрямую, а не угадывать его перебором.

## Первый triage — 28 мая 2026

Первая формальная попытка триажа моста случилась на второй день проекта
и дала результат, который не изменился ни разу за 77 дней: «zero
source-supported routes» — ни один из опробованных на тот момент
маршрутов не имел опоры в исходном материале теории. Это не было
преждевременным пессимизмом. Как показывают следующие три главы, каждая
последующая, более тщательно проработанная попытка приходила к тому же
самому месту с разных сторон.
