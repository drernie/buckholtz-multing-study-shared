# 2.2 — Обратная задача плохо поставлена

## Ключевой факт, из которого следует всё остальное

12 июня 2026 года, прямо из таблицы A1, был получен один график, который
задал форму всей последующей охоты за мостом (воспроизведён живым
перезапуском как F2, `docs/BOOK/figures/f2_epsilon_nonmonotone.py`):

```
ε(z) = (H_MULT/H_FLRW)² − 1
```

**ε(z) немонотонна: пик при z = 0.40, ε = 0.228.** Функция растёт от z=0
до z≈0.4, затем убывает.

## Почему это делает обратную задачу почти неразрешимой обычными средствами

Если бы k_A(z) была монотонной функцией — а любой стандартный физический
вывод (вириальная теорема, функция масс Press-Schechter, космологическая
плотность скоплений) даёт именно монотонную зависимость от z — то и ε(z)
была бы монотонной. Наблюдаемый пик логически требует, чтобы k_A(z),
которую использовал автор, была **немонотонной**. Ни один стандартный
физический механизм этого не даёт сам по себе.

```
z:    0.06  0.14  0.25  0.40  0.65  1.00  1.50  2.10  3.20  5.00  8.50
ε:    0.063 0.125 0.215 0.228 0.213 0.186 0.214 0.171 0.106 0.048 0.101
                              ↑ пик                              ↑ хвост
```

Даже конец диапазона выглядит подозрительно неслучайным — второй, более
слабый подъём около z=8.5, что означает: гладкой одно-параметрической
формы, скорее всего, недостаточно даже если бы немонотонность на z=0.4
удалось объяснить.

## Что это означает для восьми последующих попыток

Каждая из атак Части II (кладбище NR-001…NR-008, глава 2.3) в конечном
счёте разбивалась именно об это условие. Постоянный или степенной мост
(NR-001, NR-002) — по построению монотонны, не могут иметь пика. Функция
масс Press-Schechter (NR-003) монотонна по определению космологической
плотности. Вириальная теорема плюс функция масс (NR-004) даёт
`k_A ∝ H(z)^(4/3)` — снова монотонно. Даже гипотеза о выборке по эпохе
слияний скоплений (NR-008), которая по крайней мере не была тривиально
монотонной, дала недостаточную корреляцию (r=0.682 против требуемых 0.75)
и не объясняла вторичный подъём при z=8.5.

Обратная задача была не просто трудной — она требовала механизма, которого
не даёт ни одна из стандартных астрофизических моделей формирования
скоплений, известных проекту. Одна строка, суммирующая главу: известно,
*что* вычислил автор (таблица результата); неизвестно, *с какими входными
функциями скоплений* — а стандартная физика не позволяет их восстановить,
потому что результат немонотонен, а все стандартные k_A(z) монотонны.
