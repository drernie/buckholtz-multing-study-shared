# Фаза B — 10 графиков, все воспроизводимы

Каждый `.py` — самостоятельный скрипт: читает реальный файл из репозитория
(или честно перезапускает уже существующий скрипт этого проекта), строит
`.png` рядом с собой. Ни один график не «по мотивам» — источник данных
указан в докстринге каждого файла, и хотя бы один число оттуда напечатано
в stdout при запуске для сверки.

```bash
cd buckholtz-idm-multing-mvp
python docs/BOOK/figures/f1_commit_timeline.py
# ... и так для f2..f10
```
