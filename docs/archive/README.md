# docs/archive — superseded snapshots

Dated documents kept for history. **Nothing here is the current state of the
project.** They are retained unrewritten because this project does not silently
correct its own record: a superseded document plus a dated flag explaining what
overtook it is more useful than a quiet edit, and the incremental trail is
itself evidence that conclusions were not retrofitted.

[`PROGRAM_CLOSEOUT_LEDGER.md`](../../PROGRAM_CLOSEOUT_LEDGER.md) (the 1–2 page
claim-by-claim index) and
[`CURRENT_EVIDENCE_STATE.md`](../../CURRENT_EVIDENCE_STATE.md) (the evidence
behind it).
