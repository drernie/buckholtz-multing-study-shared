# docs/meta — process and methodology

How this project works, as distinct from what it found. Nothing here is
evidence for or against any physical claim, and nothing here is a status
report — these documents are slow-moving by design, so their dates are not
staleness.

For findings and current state:
[`PROGRAM_CLOSEOUT_LEDGER.md`](../../PROGRAM_CLOSEOUT_LEDGER.md) and
[`CURRENT_EVIDENCE_STATE.md`](../../CURRENT_EVIDENCE_STATE.md), both at the
repository root. For the operating rules an agent or contributor must follow,
[`CLAUDE.md`](../../CLAUDE.md).
