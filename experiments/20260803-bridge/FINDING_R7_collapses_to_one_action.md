## The question

R7 (handoff, independently re-derived this session — see the earlier
`GATE1_2` file) showed that three *separately posited* source equations for
three *separate* fields φ, σ, ξ reproduce the radial powers 1/r, 1/r², 1/r³.
That leaves an obvious follow-up: are φ, σ, ξ really three independent
fields needing three independent couplings — or are they secretly the Taylor
coefficients of *one* field, generated by *one* nonlinear equation? The
handoff's own phrase — "one propagator's derivatives" — already suggested
the latter without checking it.

## What was tested

A single scalar Φ, static, in the source-free region (r > 0), governed by
the field-dependent-kinetic Lagrangian

```
L = 1/2 · f(Φ) · (dΦ/dr)^2 ,      f(Φ) = 1 + 2εΦ
```

Its Euler–Lagrange equation is `f(Φ)·∇²Φ + (1/2)f'(Φ)·(∇Φ)² = 0`. Expand
`Φ = φ + εA + ε²B + ...` with `φ = 1/r` (which solves the free equation for
r > 0), and read off the equation satisfied by each order.

## Result

```
O(eps^0):  laplacian(phi) = 0                        [phi = 1/r, given]
O(eps^1):  laplacian(A)   = -(dphi/dr)^2              [same as R7's sigma eqn]
           => A (particular) = -1/(2 r^2)             EXACT match to R7's sigma
O(eps^2):  laplacian(B)   = 4/r^5
           R7's own ansatz laplacian(xi) = -phi*(dphi/dr)^2 = -1/r^5
           ratio (this action / R7 ansatz) = -4        constant -> same functional form
```

Both orders come out **the same functional form** as R7's hand-posited
equations, from a **single** Lagrangian — not three independently chosen
source terms. The first order matches with coefficient 1 (exact); the second
matches up to a constant rescaling of ε² (−4), which just means R7's own
choice of overall normalisation at that order was arbitrary to begin with —
the handoff never fixed it either.

**Verified with `sympy.dsolve`**, not by hand — same discipline as the
original R7 check.

## What this establishes

R7's claim ("one propagator's derivatives generate the radial ladder") is
now **stronger than a scaling coincidence**: there is an explicit, simple,
named class of action — a canonical scalar with a **field-dependent kinetic
normalisation**, `f(Φ) = 1 + 2εΦ` — whose static equation of motion
reproduces the whole cascade at both orders checked, self-consistently, with
one coupling constant (ε), not three unrelated ones.

## A new, concrete connection to NR-019 (previously only [WEAK-CONSISTENT])

`f(Φ) = 1 + 2εΦ` is exactly a `P(X, Φ)`-type kinetic function — the same
class of structure NR-019 flagged as being in tension with an exact
ghost-condensate limit. Here that tension becomes a **specific, calculable

```
Φ_ghost = -1/(2ε)
```

For Φ > Φ_ghost the propagator is ordinary and healthy; approaching or
crossing Φ_ghost is exactly the P_X→0 pathology NR-019 described in the
abstract. This is a genuine sharpening — NR-019 is no longer just "consistent
with the literature," it now has a concrete field-value boundary *within this
specific witness action* that a real calculation could locate relative to the
MULTING force law's actual parameter values.

## What this does NOT establish — scope, stated plainly

- **This is a flat-space, static, spherically-symmetric witness, not a
  Lorentz-covariant spacetime action.** I minimised a 3D energy functional
  and solved the resulting ODE in r. A genuine covariant completion needs
  `g^{μν}∂_μΦ∂_νΦ f(Φ)` varied in full spacetime, checked for a sensible
  time-dependent limit, causality, and a well-defined stress-energy tensor —
  none of that was done here. This shows the *static building block* such a
  theory would need to contain, not the theory itself.
- **Not unique.** Only one ansatz (`f` linear in Φ) was tried, and it worked.
  Other functional forms might reproduce the same asymptotic cascade;
  uniqueness was not tested.
- **The `A3, A4` two-body coefficient dependence is still not reproduced.**
  This action has one coupling (ε); MULTING's real dipole and quadrupole
  terms depend on both objects' masses and radii independently. Nothing here
  shows how ε maps onto that dependence.
- **Nothing about cosmological magnitude.** Exactly the separate, harder
  question C4/§6 of the technical memorandum already addresses for the
  pair-fluid route; untouched here.
- **The −4 rescaling at second order is unexplained**, not just unexplored —
  it is not yet clear whether it is forced by the theory or an artefact of
  the particular ansatz chosen.
